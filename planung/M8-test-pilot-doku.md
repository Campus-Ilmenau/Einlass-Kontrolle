# M8 – Test, Pilot & Dokumentation

**Ziel:** Das System hat sich an einem echten Abend bewährt. Admins und Kontrolleur:innen können es ohne Entwickler:in bedienen.

## Aufgabe 8.1 – Testphase
- [ ] Testplan: alle Rollen, Randfälle (Geburtstag heute, abgelaufener Account, leere Listen, mehrere Listen-Treffer)
- [ ] Lasttest: 5 Geräte scannen gleichzeitig
- [ ] Gerätetest: verschiedene iPhones und Androids, Tablet
- [ ] Probeaufbau im Club (Reichweite des WLANs, Licht am Einlass)

## Aufgabe 8.2 – Pilotabend
- [ ] Pilot-Club und -Termin festlegen
- [ ] Parallel Papier-/Sichtkontrolle als Backup
- [ ] Feedback der Kontrolleur:innen sammeln
- [ ] Probleme als Issues erfassen und priorisieren

## Aufgabe 8.3 – Dokumentation
- [x] **Kurzanleitung Kontrolleur:in** (1 Seite, laminierbar): WLAN verbinden, Login, Scannen, Fehlerbehebung, deutsch und englisch ([docs/anleitung](../docs/anleitung/))
- [ ] **Admin-Handbuch**: Vorbereitung (Ethernet, Update prüfen, Listen, Veranstaltung, Accounts, herunterfahren)
- [ ] **Checkliste Aufbau am Abend** (1 Seite): Strom an → Uhrzeit prüfen → Veranstaltung „geplant/aktiv“? → Kontrolleur:innen einloggen
- [ ] **Technik-Doku**: Pi aufsetzen, Update, Backup, Zertifikat erneuern
- [ ] Datenschutz-Aushang

## Aufgabe 8.4 – Abschluss
- [ ] Feedback einarbeiten (Bugfix-Release)
- [ ] Übergabe an die Clubs bzw. Verantwortliche festlegen
- [ ] Backlog für Version 2 (z. B. Event-Konzept, Statistik, mehrere Clubs)

## Definition of Done
- Mindestens ein Abend erfolgreich mit dem System durchgeführt
- Doku ist vollständig und von jemand Unbeteiligtem getestet
